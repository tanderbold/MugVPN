MugVPN 0.3.0: several OpenVPN connections at once on macOS, each with its own routes and DNS.

## New

- **Web sign-in for servers that require it.** openvpn now tells the server which sign-ins MugVPN can do (`IV_SSO`:
  openurl, webauth, crtext), so servers that defer the password check to a sign-in page (single sign-on, Access
  Server) work: MugVPN opens the page and the tunnel comes up once you have signed in.
- **Privacy policy** in About (and on [the site](https://tanderbold.github.io/MugVPN/privacy.html)): MugVPN
  collects nothing and has no servers of its own; the only request besides your VPN servers is Apple's
  captive-portal check after a network change.

## Fixed

- An IPv6 route a server pushes again (as after a reconnect of its own) no longer ends the connection.
- A dynamic challenge arriving while its prompt is still open waits for your answer instead of opening the
  credentials dialog over it.
- A profile is read through one checked file descriptor: a link, a FIFO or a device in its place is refused at once
  and never hangs the app.
- VoiceOver reads each checkbox in the connection's options with its own words, not only its row's heading.

## Under the hood

- The rules MugVPN applies (routes, DNS by domain, which connection gets all names, kill switch blocks, IPv6 and DNS
  protection) are now a separate planner, tested on their own; the privileged helper applies its plan. The
  interface is a library over the connection logic, which talks to openvpn through typed commands and events. The
  behaviour is the same, now covered by more tests.
- Licensing: the notices carry each bundled LZ4 source file's own notice; MugVPN's change to openvpn
  (`tools/patch-openvpn-privsep.py`) is marked GPL-2.0 with OpenVPN's linking exceptions extended to it, and every
  openvpn file it changes says so. Each release now carries its complete corresponding source
  (`MugVPN-0.3.0-source.tar.gz`, below).

## Bundled

openvpn 2.7.8 (with MugVPN's privilege-separation patch, running without root), OpenSSL 3.5.9, LZ4 1.10.0, LZO 2.10.

## Install

`brew install --cask tanderbold/tap/mugvpn`, or the DMG below (signed with a Developer ID and notarized; its SHA-256
beside it). macOS 13 or later, Apple silicon and Intel.
